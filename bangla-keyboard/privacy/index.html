Privacy Policy & Data Safety

Comprehensive data safety disclosure for the Bangla Keyboard Android application published by Infomity.

Package: com.infomity.banglakeyboard Publisher: Infomity Effective Date: November 1, 2026 Target API: Android 8.0+ (API 26+)

Executive Summary: Zero Data Collection Guarantee

Bangla Keyboard is built from the ground up as a strictly offline, zero-telemetry tool. The application is architecturally designed without network socket access:

🚫 Zero Network Permissions android.permission.INTERNET is not requested in AndroidManifest.xml. The OS prevents any network sockets.
🔒 No Keystroke Logging What you type is processed in volatile memory for rendering and immediately discarded. Never saved to persistent disk.
📦 100% Offline Vocabulary All 45,000+ words and n-gram suggestions are pre-packaged directly inside the application binary.
🛡️ Zero Third-Party Trackers No Google Analytics, Firebase, Facebook SDK, crash reporters, or advertising frameworks are bundled.

1. Information We Do Not Collect

Unlike many modern keyboards that transmit user telemetry to remote cloud servers for analysis, Bangla Keyboard does not collect, record, transmit, share, or sell any personal information or usage statistics. Specifically:

  • Keystroke & Input Text: We do not log, store, or monitor any text, passwords, credit card numbers, personal communications, or search queries you type.
  • Personal Identifiers: We do not collect names, email addresses, phone numbers, contacts, device identifiers (IMEI, Android ID, MAC address), or IP addresses.
  • Location Data: The application does not request or access GPS, coarse location, or cell-tower data.
  • Usage Analytics: We do not collect behavioral telemetry, session duration, keypress counts, or feature interaction metrics.

2. Device Permissions Declaration

To ensure complete auditability, the application requests only the minimum system permissions required to operate as an Android Input Method Editor (IME):

  • android.permission.VIBRATE — (Optional) Used exclusively to provide haptic tactile feedback when physical key touches occur. This is managed locally by Android's Vibrator service.
  • android.permission.WAKE_LOCK — (System standard) Handled by the Android OS framework to keep the keyboard UI responsive during active typing.

Network Permission Absence: Neither android.permission.INTERNET nor android.permission.ACCESS_NETWORK_STATE is present in our manifest. As a result, the Android operating system enforces a strict sandbox boundary that physically prevents the app from creating network sockets, DNS queries, or background web requests.

3. How Typing & Phonetic Suggestions Work

Bangla Keyboard operates using an on-device rule-based phonetic engine and an offline statistical frequency lexicon:

  • Ephemeral RAM Processing: When you press keys (e.g. a-m-i), the characters are processed in local volatile RAM by the InputMethodService to compute candidate Bengali matches (আমি, আমরা).
  • Offline Pre-compiled Dictionary: Word suggestions are drawn from an internal static database derived from the CC0-licensed AI4Bharat IndicCorp v2 corpus. No queries leave your phone.
  • Automatic Discard: Once a word is committed to your active text field, intermediate buffer state is cleared from memory.

4. Sensitive Field Protection (Passwords & PINs)

Bangla Keyboard inspects Android's EditorInfo flags passed by the calling application:

  • When an input field is marked as TYPE_TEXT_VARIATION_PASSWORD, TYPE_TEXT_VARIATION_VISIBLE_PASSWORD, or TYPE_NUMBER_VARIATION_PASSWORD, the keyboard immediately switches to standard numeric/QWERTY mode.
  • Suggestion caching and custom dictionary recording are completely disabled during password entry.

5. Third-Party Services and SDKs

Bangla Keyboard is built without third-party closed-source SDKs. We do not integrate:

  • Advertising networks (Google AdMob, Unity Ads, AppLovin, etc.)
  • Analytics frameworks (Google Firebase Analytics, Mixpanel, AppsFlyer, Segment, etc.)
  • Cloud crash reporting tools that scrape logcat (Crashlytics, Sentry, Bugsnag)

6. Children's Online Privacy Protection (COPPA & GDPR-K)

Because Bangla Keyboard does not collect or transmit personal information of any kind from any user, it fully complies with the Children's Online Privacy Protection Act (COPPA) and the EU General Data Protection Regulation (GDPR / GDPR-K). The application is completely safe for users of all ages, including children under 13.

7. Dataset Attribution

The phonetic dictionary rankings bundled within the APK utilize public lexical frequency counts from the AI4Bharat IndicCorp project developed by IIT Madras, licensed under CC0 / permissive open licenses. We thank the researchers for advancing open Indian language technologies.

8. Verification & Security Auditing

Any security researcher, developer, or user can independently verify these privacy guarantees:

  • APK Decompilation: Decompile the release APK using jadx or apktool and inspect AndroidManifest.xml to confirm the complete absence of INTERNET permissions.
  • Network Monitoring: Inspect active network connections using tools like PCAPdroid, Wireshark, or Android Studio Network Profiler — zero packets are dispatched.
