Up and Running in Three Steps

You need Node.js 20+ and at least one of claude, gemini, agy or codex installed on the PC, and Android 8.0+ on the phone.

01

Set Up the PC Host

On the PC (Node.js 20 or newer), run one command. It checks your setup, installs the host, starts it and registers it to start at every sign-in, running as you. It ends by showing the pairing QR code.

npx @infomity/remogent@latest setup
02

Install App & Pair with QR

Install Remogent from Google Play on your phone. Put the phone on the same Wi-Fi as the PC. In the app, tap Scan QR to pair on the first screen and scan the code the PC shows. If a host is already paired, open the drawer, expand the host card and tap Pair new host. To show the code again, run remogent pair on the PC. No typing needed; the app verifies the pinned fingerprint and connects.

03

Start a Chat

Pick an engine, a working folder and a permission mode, then prompt the agent. Watch its reasoning and tool calls stream in, and approve actions as they come.

Want it away from home? Install Tailscale on both devices and run remogent pair again.

Frequently Asked Questions

Quick answers about connectivity, cost and platform support.

Does Remogent send my code to the cloud?

Remogent itself does not. The phone connects directly to your PC. Of course, the agent you run (Claude Code, Gemini CLI, Antigravity CLI or Codex CLI) talks to its own provider exactly as it does in your terminal.

What does it cost?

Nothing recurring. Remogent is free to use. Tailscale's free personal plan is optional if you want access away from home. Support the studio on Patreon if it helps you.

Which computers can host it?

Windows is the tested host. macOS (launchd) and Linux (systemd) autostart backends are included but have had less real-world testing, so expect rough edges there.

Is my PC exposed to the internet?

The host listens on your network, and every connection needs the pairing token and the pinned certificate. Do not forward its port on your router; use Tailscale for access away from home. Rotate the secret any time with install --rotate.

Where do I download the Android app?

Install Remogent directly from Google Play (package io.github.infomity.remogent). Once installed, run npx @infomity/remogent@latest setup on your computer to start the host daemon and display the pairing QR code.

Can this page be used as the App Support URL on Google Play Console?

Yes. This URL (https://infomity.github.io/remogent/) satisfies Google Play requirements for the App Website & Support URL, corresponding to package io.github.infomity.remogent, and links directly to our standalone Privacy Policy.
